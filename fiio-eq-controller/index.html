Profile

The TINY A's PEQ is ten bands at fixed centres — 32, 64, 125, 250, 500 Hz, 1, 2, 4, 8 and 16 kHz. A profile exported from another device can carry other frequencies, and a band that has wandered out of its slot is a filter in the wrong place: the knob shapes the right slot, but that slot does not sound like 32 Hz any more. Restore puts the ten centres back and leaves every gain, Q and type alone.

Pick the slot before pressing Save — saving overwrites whatever is already stored there. The TINY A has no separate save command, so writing into the selected USER slot is what stores the curve. Importing applies a profile immediately — you can also drag an .xml file straight onto this page.
